## API Server Flow

### Outbound

The WMS receives already-normalized outbound instructions from a client OMS, ERP, uploaded file, EDI file, or manual operation.

```text
POST /api/outbound-orders
POST /api/outbound-orders/{orderId}/allocate
POST /api/outbound-waves
POST /api/picking-tasks/{taskId}/confirm
```

- Outbound order intake stores client-owned shipment requests.
- Allocation moves quantities from `Inventory.availableQuantity` to `Inventory.allocatedQuantity`.
- Allocation details retain source inventory and location so picking tasks can be generated by location.
- Picking confirmation updates picking task, outbound order line, and allocation quantities.

### Inbound

```text
POST /api/receiving-orders
POST /api/receiving-orders/lines/{lineId}/receive
POST /api/putaway-tasks
POST /api/putaway-tasks/{taskId}/complete
```

- Receiving orders represent client-owned inbound requests.
- Receiving line confirmation records inspected inbound quantity.
- Putaway tasks split a received line across target locations.
- Putaway completion increases client-owned location inventory.
